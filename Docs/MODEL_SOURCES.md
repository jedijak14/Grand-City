# Model sources — included library and asset status

## Starter library

The uploaded starter set contains 15 public GLB samples. A new original vehicle prototype,
`grandcity_arden_gt.glb`, is generated by `Tools/CreateGrandCityArdenGT.py` into the same folder.
The generated asset is currently a workspace output; it is not yet committed through Git LFS.

| `astronaut.glb`, `horse.glb` | modelviewer.dev shared assets |

These sample assets are for prototyping. **Re-check each asset's current license and attribution
requirements before commercial or public shipping.** Project-created procedural geometry is not
an authored brand/model replica; it still needs visual review, material tuning, Blueprint
assembly, scale checks, collision setup, and in-editor testing before use in a build.

The generated Arden GT GLB is 4.2 MB and approximately 479 × 202 × 167 Unreal centimeters,
with nine material-group nodes, GLTF normals, and 176,016 triangles. A CPU software-rasterized
preview was used for basic occlusion and silhouette inspection; this is not an Unreal render.
The asset is not an animated or deformable body asset by itself. Vehicle body damage requires a CPU-accessible mesh
and is currently a visual surface-dent approximation, not structural soft-body physics.

## Rigged clothing and character source added

Six Quaternius character/outfit GLBs are now included under `ModelLibrary/Clothing/Quaternius/` (male/female casual, formal, swimwear, plus a tactical-police reference). The source is CC0; asset credits and provenance are recorded in that folder's `ASSET_CREDITS.txt`. They were converted to uncompressed, dequantized GLB for importer compatibility and validated as glTF. They are full characters with multiple skinned meshes and animations—not drop-in clothing overlays. Unreal import, skeletal mesh assembly/retargeting, and materials still need editor validation before use on the current character rig.

`Tools/ImportModels_Editor.py` now imports this folder to `/Game/Gridlock/Characters/Clothing`. This only imports the files; it does not retarget skeletons, set up outfit presets, or turn on cloth simulation.

Free3D was reviewed for an explicitly commercial-use asset: Camille Kleinman's Hanging Shirt is a static OBJ and not suitable as wearable clothing. It was not copied into the project. Free3D model terms are per asset; verify the exact license and rig/format before adding future assets.

## High-detail free sources (verify every license)

Sketchfab and Fab downloads may require an account. Workflow: download a model with a license
that permits the intended use, keep author attribution in `CREDITS.txt`, place `.glb`/`.fbx`
files under `ModelLibrary/SketchfabDropIn/`, then run `Tools/ImportModels_Editor.py`.

1. **Sketchfab** — filter for Downloadable + Free and record the model page and license.
2. **Fab (Epic)** — check each asset's license and redistribution terms.
3. **Mixamo** — useful for rigged characters/animations; verify account and distribution terms.
4. **Poly Haven** and **ambientCG** — CC0 materials/props; keep the source record.
5. **Quaternius / Kenney** — stylized assets; only use if that art direction is intended.

## Airport model research and original terminal asset

Online airport-model listings were checked before choosing an asset. The Free3D Madrid terminal
listing was shown at $49; LaGuardia, San Francisco, and other full-airport scene listings were
shown at $299. These are paid listings and were not downloaded or used. The pages describe
royalty-free or editorial terms, which still require reviewing the exact purchase license and
redistribution conditions. A Meshy airport tag collection and several purportedly free search
results were discovery leads only: no individual model license, source file, or Unreal import
compatibility was verified. No third-party airport model was adopted.

Instead, `gridlock_airport_terminal.glb` is an original, procedural, 13-material-batched static
model generated by `Tools/CreateGridlockAirportTerminal.py`. It models the landside and airside
glass facades, roof/trusses/skylight, canopy and original Coastline Airways signage, check-in
counters, security lanes, seating, gate podiums and portals, baggage service, restroom core,
planters, and lighting. It is original geometry (not a real terminal replica), with no third-party
model dependency. Regenerate with `python -m pip install -r Tools/requirements-models.txt` and
`python Tools/CreateGridlockAirportTerminal.py`. The output is about 397 KB and 13 material
batches. `Tools/ImportModels_Editor.py` imports it from `ModelLibrary/PublicGLB`; the starter-city builder
also imports required model groups before map creation when they are missing. It uses this terminal
at both airports and fails clearly rather than substituting a visible greybox. A hidden walkable
floor collider is retained because GLB collision import varies by Unreal version. Static mesh
import, material appearance, collision, and in-editor scale/lighting still require UE 5.8 verification.

Online discovery links: [Free3D Madrid terminal](https://free3d.com/3d-model/madrid-airport-terminal-3-5895.html),
[Free3D LaGuardia airport](https://free3d.com/3d-model/laguardia-airport-lga-6749.html),
[Meshy airport tag](https://www.meshy.ai/tags/airport), and
[TurboSquid free airport-terminal search](https://www.turbosquid.com/Search/3D-Models/free/airport+terminal).
These are research references, not asset licenses or included assets.

## Production high-poly gate — current status: failed

`Tools/ValidateProductionAssetDensities.py` parses GLB v2 triangles and reports counts against
screening floors (100k/building, 250k/terminal, 50k for other model categories). The audit is
report-only and does not block source research or asset work. The user has since superseded the
prior authorization to keep low-density assets: current low-density models are not accepted as final
production art and must be replaced by verified, higher-quality game assets. The audit scans all
106 GLBs in `ModelLibrary`; 103 fall below the current floors (for example, the speedboat has 156
triangles and the terminal 19,684). These screening floors are a sourcing signal, not a standalone
measure of visual or game quality.
`Docs/ModelGallery/index.html` links a separate CPU-rendered PNG preview for each GLB; these are not
Unreal Engine screenshots. UE 5.8 import, visual review, and playtesting remain required.

## Original Pacific Residences hero building

`gridlock_pacific_residences.glb` is an original, procedural high-rise landmark generated by
`Tools/CreatePacificResidences.py`. It is 6,614 cm tall before map scaling and contains 195,248
triangles in ten PBR atlas material batches. The generated architectural atlas is stored at
`ModelLibrary/Textures/gridlock_city_material_atlas.png`. The model includes a glazed retail podium,
16 residential levels, inset window bays, balconies with glazing/rails, repeated fins and floor
bands, planted balcony/roof edges, a screened mechanical crown, rooftop trellis, and a landscaped
forecourt. This is an original Gridlock building, not a replica or third-party asset.

The script emits `ModelLibrary/PublicGLB/gridlock_pacific_residences.glb`; the existing GLB importer
scans `PublicGLB`. `Tools/BuildStarterCity_Editor.py` now places it as the downtown residential
landmark in place of one Kenney skyscraper and adds a hidden simple collision proxy. An offline CPU
preview was rendered at `Docs/ModelGallery/individual/PublicGLB--gridlock_pacific_residences.png`.
The preview is not an Unreal screenshot. The model was reopened through Trimesh and its geometry,
texture bindings, triangle count, and bounds were checked. UE 5.8 import, PBR appearance, scale,
collision fit, LOD/Nanite performance, and playtest verification are still required; this single
landmark does not replace the other low-density city buildings or models in the library.

## Kenney community city kit integrated from GitHub

The starter-city builder uses 67 city/road static GLBs plus five car, one nature, and three
watercraft GLBs from the Kenney CC0 library, downloaded from the pinned community GitHub mirror
`shorepine/kenney` at commit `3694c6879e487c108f55677be7dd2ca75b07cc3b`. The mirror README attributes all art to Kenney and
identifies it as CC0; the included `KENNEY_LICENSE_CC0.txt` and `ASSET_CREDITS.txt` preserve the
license/source details. The selected kits are City Commercial, City Suburban, City Industrial,
and City Roads. Files and shared kit textures remain in their source subfolders under
`ModelLibrary/Community/Kenney/`.

`Tools/DownloadKenneyCityModels.py` re-downloads these pinned files through GitHub's API.
`Tools/ImportModels_Editor.py` imports the kits into separate Unreal folders; the starter-city
builder imports required source GLBs itself before constructing the map when needed. It places
sixteen distinct commercial/skyscraper models, CC0 buildings for hospital/shop/police/marina POIs,
a suburban home, tiled road/intersection meshes, landscaping trees and streetlamps. The original
airport terminals are procedural original geometry because no terminal model with a verified
compatible license was found in GitHub searches. Original transit GLBs replace the elevator guide
posts and the escalator's engine-cube treads/primitive handrails.

The Kenney van and sedan replace the shuttle and personal-car cube visuals; a Kenney speedboat
replaces the boat placeholder. The plane uses the original Coastline A320, the helicopter uses the
attributed CC BY 4.0 AW101, and a newly modeled sea-glass surfboard replaces its cube. The other
Kenney car/watercraft models are imported for future map use. The land platform receives a simple
grass material and the starter map uses the animated procedural ocean with vertex-foam material.
The starter map's Unreal execution and visual/material review remain outstanding. OpenStreetMap/
BlenderGIS may inform future roads, but ODbL obligations require review.
Cesium/Google 3D Tiles has separate account/terms and is not bundled.
