# Model sources — included library and asset status

## Starter library

The uploaded starter set contains 15 public GLB samples. A new original vehicle prototype,
`grandcity_arden_gt.glb`, is generated by `Tools/CreateGrandCityArdenGT.py` into the same folder.
The generated asset is currently a workspace output; it is not yet committed through Git LFS.

| File | Source / notes |
|---|---|
| `grandcity_arden_gt.glb` | Original procedural design for Grand City, generated in-repository. 176,016 triangles, nine PBR material groups; a static unrigged vehicle visual, not a tested gameplay asset or production-ready sculpt. Regenerate with `python -m pip install -r Tools/requirements-models.txt` then `python Tools/CreateGrandCityArdenGT.py`. |
| `soldier.glb`, `xbot.glb` | three.js r128 examples (`github.com/mrdoob/three.js`) — animated humanoid sample models |
| `cesiumman.glb`, `brainstem.glb`, `buggy.glb`, `milktruck.glb`, `fox.glb`, `duck.glb` | Khronos glTF Sample Models (`github.com/KhronosGroup/glTF-Sample-Models`) |
| `astronaut.glb`, `horse.glb` | modelviewer.dev shared assets |
| `groundvehicle.glb`, `cesiumair.glb` | CesiumGS/Cesium SampleData |
| `babyloncar.glb`, `aerobatic.glb`, `village.glb` | Babylon.js public assets (`assets.babylonjs.com`) |

These sample assets are for prototyping. **Re-check each asset's current license and attribution
requirements before commercial or public shipping.** Project-created procedural geometry is not
an authored brand/model replica; it still needs visual review, material tuning, Blueprint
assembly, scale checks, collision setup, and in-editor testing before use in a build.

The generated Arden GT GLB is 4.2 MB and approximately 479 × 202 × 167 Unreal centimeters,
with nine material-group nodes, GLTF normals, and 176,016 triangles. A CPU software-rasterized
preview was used for basic occlusion and silhouette inspection; this is not an Unreal render.
The asset is not an animated or deformable body asset by itself. Vehicle body damage requires a CPU-accessible mesh
and is currently a visual surface-dent approximation, not structural soft-body physics.

## High-detail free sources (verify every license)

Sketchfab and Fab downloads may require an account. Workflow: download a model with a license
that permits the intended use, keep author attribution in `CREDITS.txt`, place `.glb`/`.fbx`
files under `ModelLibrary/SketchfabDropIn/`, then run `Tools/ImportModels_Editor.py`.

1. **Sketchfab** — filter for Downloadable + Free and record the model page and license.
2. **Fab (Epic)** — check each asset's license and redistribution terms.
3. **Mixamo** — useful for rigged characters/animations; verify account and distribution terms.
4. **Poly Haven** and **ambientCG** — CC0 materials/props; keep the source record.
5. **Quaternius / Kenney** — stylized assets; only use if that art direction is intended.

## City layout options

- Generate a starter greybox with `Tools/BuildStarterCity_Editor.py`; replace test geometry in
  Unreal with designed, licensed meshes.
- OpenStreetMap/BlenderGIS can inform road layout, but check ODbL obligations before shipping.
- Cesium/Google 3D Tiles requires an account/API key and has separate terms; it is not bundled.
